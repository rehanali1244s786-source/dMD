# DOCK MD - WhatsApp Multi-Device Bot & Vercel Pairing Platform

## Quick Start
1. Extract this ZIP archive into a folder.
2. Rename `.env.example` to `.env` and fill in your `OWNER_NUMBERS` and `MONGODB_URI`.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the bot and pairing web server:
   ```bash
   npm start
   ```
5. Open `http://localhost:3000` in your browser to generate a Pairing Code (`DOCKWIDE`) or scan the QR code in your terminal.
